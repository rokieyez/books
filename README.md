# 서가 뒤의 방

개인 서재 사이트 — 1,300여 권의 장서와 수집 아카이브.

책장인 줄 알았는데 문이었다. 벽마다 비뚤게 꽂힌 책이 하나씩 있고, 당기면 서가가 문처럼 열리며 뒤의 방이 드러난다. 사다리를 타고 끝까지 내려가면 촛불 켜진 책상 위에 오늘의 책이 놓여 있다.

## 구조

```
index.html      화면 뼈대
css/style.css   디자인 토큰과 전체 스타일 (단일 다크 세계)
js/data.js      장서 데이터 (현재 표본 — Supabase 로 교체 예정)
js/app.js       렌더링과 상호작용
```

## 로컬에서 보기

빌드 없음. 파일을 그대로 연다:

```
open index.html
```

로드맵과 개발 규약은 `CLAUDE.md` 참고.
